# 飞书多维表格设计文档

本文档详细描述医美私域CRM系统的多维表格结构。

## 1. 客户表 (Customer)

### 字段设计

| 字段名 | 字段类型 | 说明 |
|--------|---------|------|
| 客户ID | 自动编号 | 主键 |
| 姓名 | 文本 | |
| 手机号 | 文本 | **唯一索引**，防重复录入 |
| 微信名 | 文本 | 绑定企微/个微 |
| 收货地址 | 文本 | |
| 皮肤敏感史 | 多选 | 无/轻度/中度/重度/特定成分过敏 |
| 过敏成分备注 | 文本 | 具体过敏成分记录 |
| 孕期状态 | 单选 | 未怀孕/孕期(月数)/哺乳期 |
| 慢性病/高血压 | 多选 | 无/高血压/糖尿病/其他 |
| 职业 | 文本 | |
| 收入水平 | 单选 | 0-3000 / 3000-8000 / 8000-12000 / 12000-20000 / 20000-50000 / 50000以上 |
| 来源渠道 | 单选 | 抖音/视频号/小红书/私域转介绍 |
| 归属销售 | 人员 | **锁定字段**，创建后不可改 |
| 首次下单时间 | 日期 | **公式/查找**，取该客户最早订单日期 |
| 最近下单时间 | 日期 | **公式/查找**，取该客户最新订单日期 |
| 购买品类标签 | 多选 | **公式/查找**，累计该客户所有订单品类 |
| 意向标签 | 多选 | 意向水光/意向修护/意向祛痘/意向紧致/暂不考虑/高预算/低预算 |
| 复购次数 | 数字 | 公式计算 |
| 状态 | 单选 | 新客/已触达/已成交/复购/流失 |
| 创建时间 | 创建时间 | 系统字段 |

> **注**：首次下单时间、最近下单时间、购买品类标签、最近状态 均由飞书多维表格的公式/查找字段自动维护，代码只读不写。

### 视图设计

- **全部客户**：管理员可见所有记录
- **我的客户**：过滤"归属销售=我"，销售专用视图
- **新客待触达**：状态=新客，排序按创建时间
- **成交客户**：状态=已成交/复购

## 2. 订单表 (Order)

### 字段设计

| 字段名 | 字段类型 | 说明 |
|--------|---------|------|
| 订单ID | 自动编号 | 主键 |
| 关联客户 | 关联(客户表) | 选择后自动锁定归属销售 |
| 归属销售 | 人员 | 自动从客户带入，不可改 |
| 客户类型 | 单选 | 新客 / 老客 |
| 下单渠道 | 单选 | 抖音/视频号/小红书/私域转介绍 |
| 付款方式 | 单选 | 微信收款 / 颜控二维码收款 / 充值扣款 |
| 关联产品 | 关联(产品表) | 多选，订单关联的产品 |
| 应收金额 | 查找引用 | SUM(订单明细.小计)，自动计算 |
| 实收金额 | 数字 | 手填，实际收款额 |
| 优惠金额 | 公式 | `应收金额 - 实收金额`，自动计算 |
| 退款金额 | 数字 | 后补，影响实收 |
| 备注 | 文本 | 客户特殊要求 |
| 操作状态 | 单选 | 待操作 / 已完成 |
| 操作日期 | 日期 | **回访节点计算基准** |
| 任务生成状态 | 单选 | 待处理 / 已生成任务 |
| 创建时间 | 创建时间 | 系统字段 |

### 视图设计

- **全部订单**：管理员视图
- **我的订单**：归属销售=我
- **待操作订单**：操作状态=待操作
- **已完成待生成**：操作状态=已完成 AND 任务生成状态=待处理

## 3. 充值客户管理表 (PrepaidCustomer) 🆕

### 字段设计

| 字段名 | 字段类型 | 说明 |
|--------|---------|------|
| 记录ID | 自动编号 | 主键 |
| 关联客户 | 关联(客户表) | 充值客户 |
| 类型 | 单选 | 充值 / 消费扣款 |
| 金额 | 数字 | 充值金额(正) 或 扣款金额(正) |
| 当前余额 | 数字 | **公式**：累计充值 - 累计扣款 |
| 关联订单 | 关联(订单表) | 扣款时关联订单（充值时可空） |
| 收款方式 | 单选 | 微信收款 / 颜控二维码收款 / 充值扣款 |
| 时间 | 日期 | 充值/扣款日期 |
| 归属销售 | 人员 | 自动从客户带入 |
| 备注 | 文本 | |
| 创建时间 | 创建时间 | 系统字段 |

### 业务规则

- 只有充值过且**当前余额 > 0**的客户，才能在订单中选「充值扣款」
- 订单付款方式 = 充值扣款 → 必须从余额扣足，余额不足**阻止成交**
- 每次扣款创建一条类型=消费扣款的记录，关联对应订单
- 当前余额 = SUM(类型=充值的金额) - SUM(类型=消费扣款的金额)

### 视图设计

- **全部记录**：管理员视图
- **充值记录**：类型=充值
- **消费记录**：类型=消费扣款
- **余额告警**：当前余额 < 500（可自定义阈值）

## 6. 回访任务表 (FollowUpTask)

### 字段设计

| 字段名 | 字段类型 | 说明 |
|--------|---------|------|
| 任务ID | 自动编号 | 主键 |
| 关联订单 | 关联(订单表) | |
| 关联客户 | 关联(客户表) | 自动从订单带入 |
| 归属销售 | 人员 | 自动带入 |
| 回访节点 | 单选 | 操作后1天(回访)/2天/3天/7天/15天/30天 |
| 计划回访日期 | 日期 | 根据节点自动计算 |
| 任务状态 | 单选 | 待回访/已完成/超时未回访/已取消 |
| AI话术 | 文本 | DeepSeek生成，销售可复制 |

| 创建时间 | 创建时间 | 系统字段 |

### 视图设计

- **销售工作台**：归属销售=我 AND 任务状态=待回访，按计划日期排序
- **今日待办**：计划回访日期=今天 AND 任务状态=待回访
- **超时预警**：任务状态=超时未回访，标红显示
- **已完成回访**：任务状态=已完成

## 公式字段示例

### 客户表 - 复购次数

```
COUNTIF(订单表.关联客户, 当前记录.客户ID) - 1
```

### 充值客户管理表 - 当前余额

```
SUMIF(关联客户, 当前记录.关联客户, 类型, "充值", 金额)
- SUMIF(关联客户, 当前记录.关联客户, 类型, "消费扣款", 金额)
```

### 回访任务表 - 超时预警

```
IF(AND(计划回访日期 < TODAY(), 任务状态 = "待回访"), "超时", "正常")
```

## 仪表盘配置

### 核心指标卡片

| 指标 | 数据源 | 计算方式 |
|-----|-------|---------|
| 今日新增客户 | 客户表 | 创建时间=TODAY() |
| 今日成交额 | 订单表 | 创建时间=TODAY() → 实付金额求和 |
| 今日回访完成率 | 回访任务表 | 今日已完成 / 今日应回访 |
| 待回访任务数 | 回访任务表 | 任务状态=待回访 |
| 超时任务数 | 回访任务表 | 任务状态=超时未回访 |

### 销售排行榜

- 分组维度：归属销售
- 指标：成交额、回访完成率、复购率
- 时间范围可选：本周/本月/本季度

## 权限角色配置

| 角色 | 权限范围 |
|-----|---------|
| 管理员/老板 | 全部数据 + 仪表盘 + 配置 |
