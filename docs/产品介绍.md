# 医美 CRM 系统 — 使用指南

---

## 一、这个系统能做什么

简单说，系统帮你管三件事：**客户、订单、回访**。

以前这些全靠在 Excel 里手工记，现在换成了飞书表格，数据存在线上了，但光有表还不够 — 谁来记？什么时候该回访客户了？每天业绩怎么样了？这些靠人盯太累。

所以系统做了自动化：

**帮销售做的事：**
- 告诉你今天该回访哪些客户，按什么话术聊
- 每天推日报表单给你，填完就行，不用进表格

**帮老板做的事：**
- 每天早上 8 点推简报，一眼看完所有销售的业绩进度
- 每周末提醒你去填下周的目标

**系统自动做的事：**
- 客户做完项目后，自动在 1 天、2 天、3 天、7 天、15 天、30 天生成回访任务
- 谁逾期没回访，自动标出来并提醒
- 每天检查谁没填日报，催促补交

## 二、上线前要准备好的

### 1. 每个人都给 bot 发一条消息

这个很重要。飞书的规则是：bot 不能主动给没见过的人发消息。所以每个要用系统的人（销售 + 老板），**都得先给 bot 随便发一条消息**，发个"hi"就行。

发完以后，bot 才能推送东西给你。

目前王君军已经发过了。秦璐璐和所有销售还没发。

### 2. 数据核实

系统里已经导入了历史数据，但自动导入难免有漏的。以下三件事需要人工对一下：

- **68 条订单不知道属于哪个客户**：因为原 Excel 地址里没写手机号。找到对应客户后手动关联一下就好。
- **3 条订单没有产品明细**：产品名写得太特殊，系统没认出来。确认一下买了什么产品，补上明细。
- **1 条 4/19 的 ¥36 订单**：既没客户也没明细，确认为什么情况。

### 3. 老板填好本周目标

每周六或周日，老板需要去目标表里，给每位销售设定这周的两个目标：
- **业绩目标**：这周要做多少业绩
- **触达目标**：这周要跟多少客户沟通

如果没设目标，系统不知道进度该跟谁比，晨报上那个销售的数据就是空的。

### 4. 先试跑一天

正式开自动之前，建议手动跑一天看看推送内容对不对。确认没问题再开 cron。

## 三、日常使用

### 销售每天做什么

**收到三条消息：**

**早上 8:00 — 晨间简报**
```
📋 今日回访清单

· [3天回访] 刘婷婷 | 产品: 胶原蛋白精华液 | 状态: 复购 | 意向: 紧致
  💬 刘婷婷上次购买胶原精华液后反馈不错，可以问她需不需要搭配...
· [7天回访] 张美美 | 产品: 溶脂 | 状态: 新客
  ...

本周业绩gap: ¥3,200
本周触达gap: 8
```
上面列出了今天要回访的客户、他们用过什么产品、目前是什么状态和意向，还有 AI 帮你写的话术。下面是这周还差多少业绩和触达。

**下午 14:00 — 午后提醒**

提醒你今天还有哪些没做完的回访，以及跟目标的差距。

**晚上 18:30 — 日报推送**

一个表单链接，点开填：
- 今天跟几个客户沟通过
- 其中几个是有效沟通
- 新增了几个客户
- 成交了几单
- 今天有什么总结（选填）

填完提交就行，不用进表格。

**日常还要做的事：**

- **来了新客户** → 在客户表里登记（姓名、手机号、地址、来源等）
- **成交了新单** → 在订单表里记一笔（关联上客户、选好产品、填上实收金额），然后在订单明细表里把每个产品和数量列出来
- **回访任务** → 在飞书任务 App 里能看到系统推给你的待回访任务，完成后点一下"完成"就行

### 老板每天看什么

**早上 8:00 — 晨间简报（老板版）**
```
📊 晨间简报 (5月3日)
━━━━━━━━━━━━━━

🎯 本周目标进度 (5月3日 - 5月9日)

李旭兴:
  业绩: ¥2,400 / ¥20,000  12%
  触达: 3 / 30  10%

姚玲玲:
  业绩: ¥1,800 / ¥15,000  12%
  触达: 2 / 25  8%
...
━━━━━━━━━━━━━━
```
每个销售一条，目标多少、实际多少、完成百分比，一眼看完团队状态。

**周一早上 9:00 额外收到上周总结：**
```
📊 上周完成情况

李旭兴:
  业绩: 目标 ¥20,000  实际 ¥18,500  93%  (成交 8 单)
  触达: 目标 30  实际 28  93%
  回访: 42/48
```
方便周一开会直接拿来用。

### 老板每周做什么

**周末收到目标提醒 → 去目标表填下周目标。**

系统会在周五、周六、周日各提醒一次，不用担心忘记。周日晚 6 点是最后一次提醒。

### 系统自动跑的时间表

| 时间 | 做什么 |
|------|--------|
| 早上 8:00 | 发晨间简报 |
| 早上 9:00 | 生成回访任务、推送飞书任务、检查逾期、生成 AI 话术 |
| 下午 14:00 | 下午回访提醒 |
| 傍晚 18:30 | 推日报表单 |
| 晚上 20:00 | 查谁还没填日报，催 |
| 周一 9:00 | 上周总结 |
| 周五/六/日 | 提醒老板填目标 |

## 四、几个要注意的

**回访任务是怎么来的：** 不是销售自己建的。订单操作完成、状态改成"已完成"之后，系统以操作日期为起点，自动生成后续 1/2/3/7/15/30 天的回访节点。所以操作日期一定要填对。

**日报必须填：** 老板看到的"触达完成率"就是从日报里算的。不填日报，触达永远是 0，什么 gap、什么进度都出不来。

**目标要提前设：** 周目标要在周末设好，不然下周一到周六的晨报没有对比基准线。

**客户手机号尽量完整：** 系统就是靠手机号来匹配订单和客户的。没手机号的订单对不上客户，就需要人工处理。

**有人离职怎么办：** 不用一个一个客户改。跑一条命令，就能把离职员工的所有客户和待回访任务一次性转给接手的人，而且会记录流转日志。
